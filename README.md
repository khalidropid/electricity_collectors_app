# تطبيق متحصلي الكهرباء

تطبيق Flutter عربي لإدارة عمل متحصلي الكهرباء، مع شاشات للمصادقة والعملاء والقراءات والمدفوعات والتقارير والمزامنة.

## التقنيات

- Flutter / Dart
- Provider لإدارة الحالة
- واجهات Material

## التشغيل

```bash
flutter pub get
flutter run
```

لإنشاء نسخة مهيأة للإنتاج استخدم `flutter build` للمنصة المطلوبة.
